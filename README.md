# Medtronic Academy High Power 学習アプリ

Medtronic Academy High Power（CRT / ICD）の全講義資料から作成された、臨床工学技士・医療従事者向けのアクティブリコール（自力想起）＆忘却曲線学習アプリです。

不整脈治療専門臨床工学技士の学習システムを踏襲し、メドトロニック社のブランドカラーである「青と白」を基調とした洗練されたデザインで構築されています。

---

## 主な特徴と機能

### 1. 厳格な自力想起（アクティブリコール）訓練
- 選択肢に頼らず、問題文から自力で電気生理学的機序や具体的数値を思い出す1問1答形式
- 解答・解説はすべて150〜200文字程度で論理的に凝縮されたメカニズム・設定値を網羅

### 2. 忘却曲線（SM-2アルゴリズム）による復習管理
- 「忘れていた（明日復習）」「やや曖昧（3日後復習）」「覚えている（7日後/14日後復習）」の3段階自己評価
- 復習期日が到来した問題をダッシュボードに自動集計

### 3. スマートフォン完全対応（外での学習・オフライン対応）
- **完全スタンドアロン型**: インターネット接続がない環境（地下鉄、院内、電波の届かない場所）でも動作
- **自動保存**: 学習の進捗や中断セッションはスマートフォンのローカルストレージに自動保存
- **PWA対応**: ホーム画面に追加することで、アドレスバーのない全画面ネイティブアプリとして起動

### 4. 豊富な学習モード & 分析
- **クイックスタート**: 本日復習や未学習から15問を即座にピックアップして出題
- **教材・分野別演習**: CRT全8単元、ICD全11単元からピンポイントで選択可能
- **問題庫 & 全文検索**: 全239問をキーワード、分野、教材別に即座に検索・単問演習
- **学習統計**: 分野別（CRT vs ICD）の習得率、総演習数、定着済み問題数の可視化

## 外でスマホから学習する方法

### 方法A: 最も手軽な方法（ファイルをスマホに送る）
1. 本フォルダにある `index.html` をAirDrop、LINE（自分宛）、Googleドライブ、iCloud、またはメール等でスマートフォンに送信します。
2. スマートフォンのブラウザ（SafariやChrome）で開きます。
3. ネット回線がなくても、いつでもどこでも学習できます。進捗もスマホ内に保存されます。

### 方法B: スマホのホーム画面に追加してアプリ化する（おすすめ）
- **iPhone (Safari)**:
  1. `index.html` をSafariで開きます。
  2. 画面下部の中央にある「共有」アイコン（四角から矢印が出ているアイコン）をタップします。
  3. メニューから「ホーム画面に追加」を選択します。
  4. ホーム画面にメドトロニック青白の専用アイコンが配置され、タップすると全画面アプリとして起動します。
- **Android (Chrome)**:
  1. `index.html` をChromeで開きます。
  2. 右上のメニュー（3点リーダー）をタップします。
  3. 「ホーム画面に追加」または「アプリをインストール」を選択します。

### 方法C: GitHub Pages や無料ホスティングでURL化する
本フォルダをGitHubにアップロードし、Settings > Pages で「Deploy from a branch」を有効にするだけで、自分専用のURL（例: `https://<ユーザー名>.github.io/<リポジトリ名>/`）が発行され、外出先のどのスマホからでもURLにアクセスするだけで学習できます。
